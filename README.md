You can use the platform in two ways:

### 1. Launch with Local Web Server (Recommended)
Run the launcher script:
```bash
python serve.py
```
This starts the local web server at `http://localhost:8000/index.html` and automatically opens your browser.

### 2. Direct File Open
You can also directly double-click or open `index.html` in any modern browser (Chrome, Edge, Firefox, Brave).

## ⚡ Platform Features

### 1. Embedded Video Player (Two Modes)
- **Inline Embedded Player:** Exactly like GateXAIML, click any video thumbnail on a subject page to instantly play the YouTube lecture inside the card with autoplay.
- **Theater Mode / Focus Study Room:** Click "Theater" on any card to launch the fullscreen study experience:
  - Responsive wide video stage with high-definition playback.
  - Playlist drawer with auto-advancing Next / Previous lecture controls (`Alt + →` / `Alt + ←`).
  - Watched status toggle.
  - **Timestamped Personal Notes Pad:** Type notes while watching; they automatically save to your browser's localStorage.

### 2. Offline PDF Handbook Viewer
- Every subject includes its complete official handbook compiled for GATE DA.
- Click **"Read Subject Handbook PDF"** to open the built-in reader modal, or click **"Download"** to save it locally.

### 3. TCS iON GATE Virtual Scientific Calculator Replica
- Since physical calculators are prohibited in GATE, students must calculate everything on the TCS iON on-screen calculator.
- Built-in authentic replica features:
  - Exact button layout and visual styling.
  - Degree and Radian modes.
  - Trigonometric, inverse (`Inv`), and hyperbolic (`Hyp`) functions.
  - Logarithms (`ln`, `log10`), powers (`x^y`, `x^2`, `x^3`), roots (`sqrt`, `cbrt`), and factorial (`n!`).
  - Memory registers (`MC`, `MR`, `MS`, `M+`, `M-`).

### 4. Interactive Practice Arena (MCQ, MSQ, NAT)
- Questions modeled on actual GATE DA 2024 and 2025 examination questions.
- Single Correct (MCQ), Multiple Correct (MSQ), and Numerical Answer Type (NAT).
- Immediate evaluation with step-by-step mathematical solutions and accepted numerical tolerance ranges.

### 5. Interactive Syllabus & 4-Phase Roadmap
- Complete topic-by-topic official syllabus checklist with persistent progress tracking.
- Subject-wise marks weightage analysis.
- 4-Phase strategic preparation roadmap for 2027.

### 6. Formula Cheatsheets
- Rapid revision formula cards covering Linear Algebra, Probability, Calculus, Machine Learning, and DBMS.

### 7. Study Notes Journal & Progress Backup
- Centralized notebook view for all your lecture notes.
- One-click export to Markdown (`.md`) or JSON backup.

## 🏆 Blueprint to Score 70+ Marks in GATE DA 2027

1. **Phase 1 (Months 1–3):** Master Linear Algebra (Gilbert Strang), Probability Distributions (Walpole), and Python fundamentals.
2. **Phase 2 (Months 4–6):** Conquer DBMS (Normal forms, B+ Trees, SQL) and Supervised ML (Regression, SVM, Trees).
3. **Phase 3 (Months 7–9):** Cover Unsupervised ML (PCA, K-Means), AI Search (A*), and Algorithms.
4. **Phase 4 (Months 10–12):** Solve PYQs, take 15+ full-length mocks, drill with the Virtual Calculator, and revise daily with the Formula Cheatsheets.
